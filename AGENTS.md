# Cripto

PWA estática (sin build) con precios BTC/ETH en USD desde la API pública de Binance.

- Probar en local: `python3 -m http.server 8080` → http://localhost:8080
- Deploy: GitHub Pages desde la rama `main` (raíz) → https://leoonardosantana.github.io/cripto/
  - Publicar cambios: `git add -A && git commit -m "..." && git push`
- GitHub CLI instalado en `~/.local/bin/gh` (no está en el PATH por defecto).
